# Giri Krishna C M —  Portfolio

A professional, responsive static portfolio built from Giri Krishna C M's supplied CV, profile photo and FIESTAA'26 certificate.

## Included
- Arctic Neon visual theme
- Responsive desktop/tablet/mobile layout
- About, skills, projects, education and certification sections
- Profile photo
- CV in PDF and DOCX
- FIESTAA'26 certificate PDF
- GitHub, LinkedIn and LeetCode links

## Run locally
Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
Create a GitHub repository named `portfolio`, upload all files in this folder, then enable GitHub Pages from Settings → Pages → Deploy from branch → `main` / root.

The expected project URL will be:
`https://girikrishnacm.github.io/portfolio/`

Remove the space in the URL: `https://girikrishnacm.github.io/portfolio/` → `https://girikrishnacm.github.io/portfolio/`.
